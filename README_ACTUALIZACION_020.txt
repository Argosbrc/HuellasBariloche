HUELLAS BARILOCHE - ACTUALIZACION 020

Esta entrega agrega:

- Carrusel de portada con perros perdidos que estan siendo buscados.
- Fotografias, nombre, barrio y antiguedad tomados de casos reales.
- Rotacion automatica, controles manuales y acceso al caso correspondiente.
- Comunidad organizada como tablon solidario.
- Publicaciones para pedir ayuda, convocar actividades, ofrecer recursos y compartir informacion util.
- Formulario comunitario con imagenes opcionales.
- Filtros por categoria en el feed comunitario.
- Acceso protegido por sesion para publicar.

INSTALACION

1. Conservar el archivo .env.local de la instalacion actual.
2. Reemplazar el proyecto por esta version.
3. Volver a copiar .env.local.
4. Ejecutar npm install.
5. Ejecutar npm run dev.

Esta actualizacion no necesita una migracion SQL nueva.
No volver a ejecutar las migraciones 001 a 018.

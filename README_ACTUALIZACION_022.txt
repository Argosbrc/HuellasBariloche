HUELLAS BARILOCHE - ACTUALIZACION 022

- Corrige las fotografias que podian mostrarse con su tamano original sobre el mapa.
- Fija cada marcador fotografico en 42 x 42 px.
- Mantiene la foto circular, el color segun el tipo de caso y el acceso a la ficha.
- La seleccion aumenta el marcador solo un 10 %.
- No requiere ninguna migracion SQL.

Instalacion:
1. Conservar el archivo .env.local.
2. Reemplazar el proyecto por esta version.
3. Volver a colocar .env.local.
4. Ejecutar npm install y npm run dev.
